Why does my session opening list files that are not on the map?

Because files were accumulating unseen. Your project's map (MAP.md) names what each folder and each file a person uses is for, and the opening now lists every path at the project root, and every document, image or spreadsheet below it, that no map line covers — a fact, not a verdict. At the close, Claude asks once per path: a leftover working file from a session that never closed is read into the record and then offered for deletion; any other path gets a map line, a move to the folder the map says, or deletion, on your word. A no leaves it, and it is listed again next time. What tells you it worked: after a yes to a map line, the next opening lists nothing for that path.

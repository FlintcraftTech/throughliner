How do I give Claude a memory about me that every project reads?

Claude Code's own memory is kept per project, so a fact you told Claude in one project is unknown in the next. You meet this when a fresh chat in another project asks you something you have already said elsewhere. Type the memory-setup command in any project. Claude says where the memory will live, a folder named memory inside the .claude folder in your home directory, outside every project, and hands you a prompt in a box. Paste that prompt into Claude chat, which lists what it remembers about you, then paste its reply back, or save it to a file in the project's temp/ folder and say done. Claude groups the facts into small notes, shows you the list, and writes them on your yes; anything shaped like a password, a key, a card or bank number or a government identifier is left out, and you are told which lines. It then adds one line to your global instructions file, which the safety check asks you to approve, so every session loads the memory's index and opens a note when it bears on the conversation. Run the command again whenever chat has learned more: only what is new is added, and each fact that contradicts a note is shown to you to choose. The memory stays on this machine and Claude chat cannot read it. What tells you it worked: in a fresh chat in a different project, Claude gives a fact that only the memory holds, with no file pointed at.

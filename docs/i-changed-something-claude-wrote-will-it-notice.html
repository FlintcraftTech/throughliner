I changed something Claude wrote — will it notice?

Yes, the next time it reads the thing you changed: a draft you edited in the side panel when it reads it back, a file in your project when a session opens, and a post or page outside the project when it fetches it again. The session opening names the uncommitted changes the safety check's log does not show Claude making, and any captures that arrived in your queue since the last commit. A plain fix — wording, length, a typo — is accepted with no question and noted in the session's record. An edit that reverses something the record says was decided for a reason, contradicts something Claude has read, or has no reason Claude can see is asked about, one at a time. Where your edit changes or removes text, Claude searches the project for that text's distinctive words and names each place that now disagrees with you. What it cannot do: tell whose a change is for certain — a file Claude changed through a script can be named as yours — or find a contradiction written in other words. What tells you it worked: the opening line naming your changed files, or the question about your edit.

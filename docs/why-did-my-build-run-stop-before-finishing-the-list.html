Why did my build run stop before finishing the list?

One deliberate stop exists, and it is yours. A build run works down your queue from the top and builds only what sits above the --- Cleared to run above this line --- line — that line is placed at the end of each planning session, just below the last item you agreed was ready, so the run never builds anything you didn't sign off. Work that moves files or folders other work depends on gets a run of its own the same way: planning places the line straight after it and holds the rest on it. If a run stops earlier than you expected, check where your line sits — the stop is the system honouring what was set up, not a fault.
